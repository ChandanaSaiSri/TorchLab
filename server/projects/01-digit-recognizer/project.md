You will build a small handwritten-digit recognizer from scratch. The images are generated by the helper module `digits_data.py` (already available to your code): each image is a **12x12 grayscale digit** that is shifted around the canvas and covered in random noise.

```python
from digits_data import make_digits
X, y = make_digits(2000, seed=1)       # X: (2000, 1, 12, 12), y: (2000,) values 0-9
```

Four milestones take you from raw data to a model that survives noisy input:

1. **Know your data** - summarise a dataset before modelling it
2. **A first model** - a fully connected network and an accuracy function
3. **Go convolutional** - a CNN that clearly beats the MLP
4. **Ship it** - a confusion matrix and a model trained to resist noise

Your code accumulates in one file. When you pass a milestone, the next stub is added for you. Finish all four to earn the **Digit Recognizer** certificate and 250 XP.
